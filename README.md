A make.fun entry for **Fortune Cookie Wisdom for Developers** — a program that
prints exactly one fortune-cookie-style line of wisdom for developers.

## The fortune

> Your flaky test will pass on the third quiet retry — not because the code changed, but because you gave it the calm morning it was waiting for.

## How to run

```sh
python3 main.py
```

Requires Python 3.13 (standard library only — no third-party packages, no file
I/O, no network). The program prints exactly one line to stdout and nothing
else.

## Why it fits the brief

The line reads like a real fortune — a small prophecy about what *will*
happen — but it lands on one concrete developer detail, the flaky test that
only misbehaves when you are in a hurry. The twist is gentle rather than
snarky: nothing in the code is blamed, and the fix is not a clever hack but a
calmer morning, a quiet retry, a little patience offered to the machine. It
avoids the tired jokes entirely and leaves the reader with a warm, usable
truth: sometimes the system is not broken, it is just waiting for you to slow
down.
